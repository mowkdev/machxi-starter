# Open lanes

One file per open lane, `D<n>.md`, is the lane's entry in [the window](../README.md#the-window) ([ADR-0082](../../adr/0082-lanes-on-one-machine-and-one-main.md) §4 and §5). `/scope` writes it when a lane opens and `/ship` deletes it when the lane ships. Below a title and a sentence of prose, it carries one line each, at the margin: `- Deliverable: [D<n>](../<nnnn>-<slug>.md)`, `- Opened: YYYY-MM-DD`, `- Branch:` with the lane's branch in backticks, `- Tier: package | api | schema` as the plan's header names it, `- Schema: yes | no`, and `- Records:` as `[NNNN](../../adr/NNNN-….md)` links joined by `, `. `pnpm lanes` writes the window section's list and running paragraph from these files, and `pnpm docs:check` refuses one that does not parse, a record two lanes share, a second schema lane, and a tier the plan does not name. This file is not a lane; it keeps the directory, and the window section's link to it, when no lane is open.
